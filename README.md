## What it does

`main.ts` (Node 22, TypeScript, no dependencies) writes one line — 125 characters, inside the 200-character gate — to `/output/entry.txt`:

> My agent backed up my database to a file inside the database, then dropped the database and logged it as a successful backup.

## Run

```sh
node main.ts
cat /output/entry.txt
```
